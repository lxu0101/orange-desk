# 「今天学什么」输出规范（示例模式）

> 这是一个「模式」的例子：快捷按钮把这份文件交给 AI，AI 按要求输出一个 ```study 代码块，橙子把它渲染成学习进度卡片。
> 用法：把下面的「课表链接」换成你自己的课表（飞书文档、Notion 页面、本地 md 都行），删掉这段说明。

课表链接：<在这里填你的课表地址>

**如果上面的「课表链接」还是尖括号里的占位符，就什么都别读、别去别处（记忆、历史对话、其他文档）找课表，直接回复一句：「还没配置课表：打开 prompts/study.md，把课表链接填上，再点一次。」然后结束。**

读上面的课表（飞书文档用 lark-cli docs +fetch --as user --doc-format markdown 读；先用 date 核对今天日期）。规则：打 ✅ 的才算学了；没有打钩列的那几天算「待确认」。实际进度 = 从第 1 天起连续打 ✅ 到第几天；应达 = 今天在课表里是第几天；gap = 两者之间没打 ✅ 的天。按课表顺序一天一天补，今天只补 gap 里最早没学的那一天（待确认的天也跳过，往后找第一个确定没学的；如果 gap 全是待确认，就补待确认里最早的一天）。只输出一个 ```study 代码块，不要其他文字，格式如下（字段内容按课表原文写，精简到一行）：
```study
{"title":"课表名称","doc":"课表链接",
"stages":[{"name":"阶段一","weeks":"W1–2","days":14},{"name":"阶段二","weeks":"W3","days":7}],
"totalDays":21,"actualDay":5,"expectedDay":9,"actual":"阶段一 W1 第 5 天","expected":"阶段一 W2 第 2 天","gapDays":4,
"queue":[{"date":"10/17 周六","topic":"主题","where":"阶段一 W1 第 6 天","status":"today","read":"精读内容","resource":"资源内容","output":"输出练习"},{"date":"10/18 周日","topic":"输出日","where":"阶段一 W1 第 7 天","status":"next","output":"输出内容"}],
"note":"一句话提示"}
```
date 只写「MM/DD 周X」，不加括号说明。queue 里每一天都要写 read / resource / output（课表原文精简成一行；输出日没有精读和资源就不写这两个字段），界面靠这些在本机切换到下一天。queue 列出 gap 里的每一天（输出日也算一天），status 只能是 today / next / unconfirmed / todo。
